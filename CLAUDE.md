# Manabase

Express + SQLite (knex) backend in /backend, React + Vite frontend in /frontend.
Deployed as a single Docker image (frontend built, served by Express).

## Commands
- Backend dev: `cd backend && npm start` (port 8080); tests: `npm test -- --run`
- Frontend dev: `cd frontend && npm run dev`; build: `npm run build`
- Full local: `test.bat` (sets ENABLE_DEV_LOGIN=true)
- Seed test users: `cd backend && npm run seed:10`
- Update land cycles: `cd backend && npm run update-cycles`

## Conventions
- DevUser (`dev@manabase.com`) is the canonical test user. Don't rename it.
- Icons: `@heroicons/react` only, no emoji in UI or backend logs.
- `list_type` values: `owned`, `proxy`, `wishlist`, `tradelist`, `optional_proxies`, `deck`
- Cardbacks config is in `backend/data/cardbacks.json`; custom images in `backend/data/cardbacks/` (served at `/cardbacks/`).
- Never commit `backend/data/*.db`, Scryfall bulk files, or CSVs.
- Future architectural/domain roadmap items are tracked in `BACKLOG.md`.

## Gotchas
- `landcycles.json` is generated by `scripts/updateLandCycles.js` (hits Scryfall API/Tagger, slow; requires rate limiting and custom `User-Agent`).
- Some tests hit live network (pricing, scryfall) or need local CSVs.
- Prod DB lives at `/data/manabase.db` (volume); `JWT_SECRET` is required in prod.

## Before saying "done"
Run frontend build and backend tests; report anything you couldn't run.
