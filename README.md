# Manabase

Manabase is a comprehensive Magic: The Gathering deck building, collection management, and social platform.

## Features
- **Deck Building & Proxy Management**: Import, build, and organize EDH decks and proxies.
- **Land Suggester & Land Base Generator**: Intelligent land recommendations based on color distribution, liked land cycles, and budget preferences.
- **Friends & Social Suite**: 
  - Steam-style friend codes and user connections.
  - Direct messaging and real-time WebSockets.
  - Friend proxy manifests and shared social interactions.
- **E2E & Unit Testing**: Robust test suites with Vitest backend tests and Playwright E2E tests.
